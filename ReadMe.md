### 🚀 Featured Projects

#### 🎭 [A Marionete (Game Engine)](https://github.com/kkphoenixgx)
A Roguelite Bullet-Hell built with a **custom 100% TypeScript engine**. Features Zero-Garbage Collection architecture and Generative AI (Ollama/LLM) for NPC decision-making.

#### 🌐 [Personal Portfolio V2](https://github.com/kkphoenixgx)
High-performance interactive experience merging **Angular 19** with **Three.js** and **Matter.js**. Demonstrates advanced memory management and rendering optimization.

#### 🛰️ [The Big Agent](https://github.com/kkphoenixgx)
Embedded Multi-Agent System inspired by "1984", utilizing **BDI logic (AgentSpeak)** for drone autonomous security operations. Built with Java and integrated with Webots/Three.js for physical simulation.
